# مطالب مرتبط هوشمند تکنوپی (TechnoPay Smart Related Posts)

افزونهٔ وردپرس برای **درج خودکار مطالب مرتبط لابه‌لای پاراگراف‌های مقاله، با تأیید ویراستار**.

## افزونه چه می‌کند؟

1. **متن مقاله را یک بار می‌خواند** و هر پاراگراف را با همهٔ نوشته‌های منتشرشدهٔ سایت مقایسه می‌کند (شباهت محتوایی TF‑IDF با پشتیبانی از فارسی: نرمال‌سازی ی/ک، نیم‌فاصله، حذف کلمات توقف و ریشه‌یابی سبک).
2. برای هر پاراگراف، **مرتبط‌ترین نوشته‌ها را پیشنهاد می‌دهد** (با درصد تطابق و کلیدواژه‌های مشترک).
3. **ویراستار تأیید می‌کند** (جعبهٔ «مطالب مرتبط هوشمند» زیر ویرایشگر): هر پیشنهاد را تأیید، تغییر یا رد می‌کند و محل درج را انتخاب می‌کند.
4. فقط **پیشنهادهای تأییدشده** در مقاله نمایش داده می‌شوند: به‌صورت باکس «بیشتر بخوانید» در **انتهای همان بخش (قبل از H2 بعدی)** یا درست بعد از همان پاراگراف. تعداد باکس‌ها محدود نیست؛ هر پاراگراف حداکثر یک باکس دارد.

متن مقاله هیچ‌گاه تغییر نمی‌کند؛ تأییدها جداگانه ذخیره می‌شوند و باکس‌ها هنگام نمایش درج می‌شوند. اگر پاراگرافی بعداً ویرایش شود، تأیید مربوط به آن «منسوخ» می‌شود، نمایش داده نمی‌شود و در جعبهٔ ویرایشگر به شما اطلاع داده می‌شود.

## نصب و استفاده

1. پوشهٔ `technopay-related-posts` را (zip کنید و) از «افزونه‌ها ← افزودن ← بارگذاری» نصب و فعال کنید.
2. «تنظیمات ← مطالب مرتبط هوشمند»: انواع نوشته، حداقل کلمات پاراگراف، حداقل درصد تطابق، تعداد گزینه‌ها، محل پیش‌فرض، ظاهر باکس (کارت یا یک خط متنی)، برچسب و دسته‌های مستثنا. برای سایت‌های دارای نوشتهٔ قدیمی یک‌بار «بازسازی ایندکس» را بزنید.
3. در ویرایش هر نوشته: **«تحلیل متن و پیشنهاد مطالب مرتبط»** ← پیشنهادها را بررسی و تأیید کنید ← **«ذخیره تأییدها»**.
   - اولین بار، پیشنهاد اصلی هر بخش از پیش علامت خورده است ولی تا «ذخیره» نزنید اثری ندارد.
   - می‌توانید نمایش باکس‌ها را برای یک نوشته خاموش کنید.
   - تحلیل روی متن فعلی ویرایشگر (حتی ذخیره‌نشده) انجام می‌شود.

## برای توسعه‌دهندگان

- ایندکس: برای هر نوشته یک بردار وزنی (عنوان ×۵، دسته/برچسب ×۳، سرتیترها ×۲٫۵، چکیده ×۲، متن ×۱) در متای `_tprp_vec_1` ذخیره می‌شود و با ذخیره/انتشار نوشته به‌روز می‌شود. نوشته‌های ایندکس‌نشده هنگام تحلیل به‌صورت تنبل ایندکس می‌شوند.
- REST (نیازمند ورود و nonce): `POST /wp-json/tprp/v1/analyze`، `/approve` و `/reindex`.
- فیلترها: `tprp_stopwords`، `tprp_max_corpus` (پیش‌فرض ۴۰۰۰)، `tprp_lazy_index_limit`، `tprp_box_html`، `tprp_thumbnail_html`، `tprp_admin_thumbnail_url`.
- داده‌ها هنگام حذف افزونه پاک می‌شوند (`uninstall.php`).
- نیازمندی‌ها: وردپرس ۶٫۰+، PHP ‏۷٫۴+ و افزونهٔ mbstring.
